# API 错误提示

聊天错误、模型列表拉取错误和模型连接测试错误显示状态码说明，并保留原始错误内容。原始错误可选择复制；连接测试支持滚动查看完整错误，复制按钮会复制说明和完整原文。

| HTTP 状态码 | 显示说明 |
| --- | --- |
| 400、422 | 请求参数有误 |
| 401 | API Key 有误，检查密钥是否正确、完整且有效 |
| 402 | API 欠费，检查余额和额度 |
| 403 | 请求被服务器风控拒绝，也可能是访问限制 |
| 404、410 | 接口或模型不存在、已下线 |
| 405、501 | 接口不支持此请求方式 |
| 406、415 | 请求内容格式不受支持 |
| 407 | 代理验证失败 |
| 408、504、522、524 | API 请求超时 |
| 409 | 请求状态冲突 |
| 411 | 请求缺少内容长度 |
| 413、414、431 | 请求内容过大 |
| 423 | 资源已锁定 |
| 425 | 服务器暂不接受此请求 |
| 426 | 接口协议需要升级 |
| 429 | 服务器限流 / 风控 |
| 451 | 地区或法规限制 |
| 499 | 服务器风控 / 请求中断，需要结合原文确认；也可能是网关或连接关闭 |
| 500 | API 服务器内部错误 |
| 502、520 | API 网关响应异常 |
| 503、529 | API 服务暂时不可用、过载 |
| 507 | API 服务器资源不足 |
| 521、523 | API 源站无法连接 |
| 525、526 | API 服务器 TLS 或证书异常 |
| 其余 4xx、5xx | 按请求错误或服务器异常说明，具体原因保留在原文中 |

说明由 `apps/flutter/app/lib/ui/common/ApiErrorText.dart` 统一管理。识别使用结构化 HTTP 状态码或供应商错误中明确的 HTTP 状态位置（如 `request failed: 403`、`list_models request failed: 403`、`HTTP 403`），不根据正文中的普通数字猜测。未识别的错误保留现有原文。此变更仅影响展示，不修改请求、重试或密钥池策略。
