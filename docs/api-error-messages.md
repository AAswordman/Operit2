# API 错误提示

聊天错误、模型列表拉取错误和模型连接测试错误显示状态码说明，并保留原始错误内容。原始错误可选择复制；连接测试支持滚动查看完整错误，复制按钮会复制说明和完整原文。

聊天首次请求和工具执行后的后续模型请求共用错误回调，重试期间的错误通过聊天角落提示显示。请求最终失败时，聊天结束流程也会发送包含原始错误的角落提示；正常完成和用户取消不发送失败提示。请求、重试和密钥池策略保持不变。

角落通知在 `AppToastHost` 渲染时同样使用统一的 HTTP 错误说明，覆盖聊天、Host 提示和 SnackBar 转入的通知。说明跟随当前应用语言，展开、选中复制和完整原始错误保持可用；正文高度按包含说明后的实际文本计算。

HTTP 400 且错误内容包含字面量 `reasoning_content` 时，统一显示“请使用支持思考回传的供应商”，引导用户在模型设置中选择 DeepSeek、OpenAI 兼容等支持思考内容回传的供应商类型，并确认与 API 接口匹配。这条组合规则应用于聊天正文、角落通知、模型列表和连接测试；其他 400 继续显示参数错误说明。结构化 HTTP 状态码仍为准，具体供应商原因保留在原文中。

自动总结、手动总结和手动插入总结的模型请求都必须传入实际错误回调，重试期间显示“上下文压缩：原始错误和重试进度”，最终失败沿用总结失败提示。已取消或被替换的自动总结任务不能继续发布提示。总结完成后的自动继续仍使用普通聊天请求与工具循环的同一错误链路。

标题生成、工具直接调用模型和定时回复生成也接入实际错误回调。标题生成与工具直接调用模型在收完流后检查终态错误，避免把失败流的部分内容当作成功结果。错误与 Token 超限回调不再提供空默认实现；没有职责的历史生命周期、通知和回调接口已删除。调用点核对与清理结果见 [模型错误回调审计](provider-error-callback-audit.md)。

| HTTP 状态码 | 显示说明 |
| --- | --- |
| 400、422 | 请求参数有误 |
| 401 | API Key 有误，检查密钥是否正确、完整且有效 |
| 402 | API 欠费，检查余额和额度 |
| 403 | 请求被服务器风控拒绝，也可能是访问限制 |
| 404、410 | 接口或模型不存在、已下线 |
| 405、501 | 接口不支持此请求方式 |
| 406、415 | 请求内容格式不受支持 |
| 407 | 代理验证失败 |
| 408、504、522、524 | API 请求超时 |
| 409 | 请求状态冲突 |
| 411 | 请求缺少内容长度 |
| 413、414、431 | 请求内容过大 |
| 423 | 资源已锁定 |
| 425 | 服务器暂不接受此请求 |
| 426 | 接口协议需要升级 |
| 429 | 服务器限流 / 风控 |
| 451 | 地区或法规限制 |
| 499 | 服务器风控 / 请求中断，需要结合原文确认；也可能是网关或连接关闭 |
| 500 | API 服务器内部错误 |
| 502、520 | API 网关响应异常 |
| 503、529 | API 服务暂时不可用、过载 |
| 507 | API 服务器资源不足 |
| 521、523 | API 源站无法连接 |
| 525、526 | API 服务器 TLS 或证书异常 |
| 其余 4xx、5xx | 按请求错误或服务器异常说明，具体原因保留在原文中 |

说明由 `apps/flutter/app/lib/ui/common/ApiErrorText.dart` 统一管理。HTTP 状态识别使用结构化状态码或供应商错误中明确的 HTTP 状态位置（如 `request failed: 403`、`list_models request failed: 403`、`HTTP 403`），不根据正文中的普通数字猜测。HTTP 400 的 `reasoning_content` 组合说明按上文规则识别。未识别的错误保留现有原文。此变更仅影响展示，不修改请求、重试或密钥池策略。
