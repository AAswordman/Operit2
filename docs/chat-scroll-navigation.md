# 聊天右侧消息导航条

导航条只接管右侧 48 个逻辑像素内开始的按压，悬停展开范围也限制在这段宽度内。从条左侧开始滑动仍由聊天正文处理。

按下立即显示消息预览，上下拖动连续选择，松手跳转一次。拖到可见刻度区域顶部或底部的 48 像素范围内时，导航条会持续向相应方向滚动；越靠近边界，滚动越快。区域较矮时，两端各占一半高度。手指拖出边界后仍然继续滚动，高亮留在可见区域端点。移回中间停止滚动，取消触摸停止滚动且不跳转。历史全部可见时无需滚动。

边缘位置与命中、绘制共用 `ChatScrollRailGeometry`。刻度区域居中显示，上下留有空白，因此不能用整个聊天视口的边缘代替刻度边缘。触摸选择和边缘滚动属于同一次按压，不通过长按时间或滑动距离切换模式。鼠标滚轮仍可单独滚动导航条。
