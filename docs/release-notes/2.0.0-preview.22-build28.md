# 2.0.0-preview.22 · Apple Build 28

对比基线：Build 27 / 2.0.0-preview.21，提交 `1e712b3de6f1642539f39e63035544069c3e9fa9`。
本次二进制：提交 `72c6240b8abdb43235622c1c7891057783e6ef97`，Apple 版本 `2.0.0`，Build `28`。
以下内容用于两端 TestFlight 的“测试内容”，不包含 CI、测试维护及其他平台专属改动。

## IOS · zh-Hans

2.0.0-preview.22 · Build 28
相较 Build 27（2.0.0-preview.21）：

• 重做聊天 Markdown 展示，统一实时输出、历史消息和复制预览中的嵌套样式、引用与表格；修复流式输出结束时末尾内容未完整显示的问题，减少逐字动画的重复排版。
• 新增聊天图片全屏预览，支持缩放和拖动，改善图注及纯图片消息布局。
• 修复文本选择过程中选择对象注销可能触发的异常。
• 修复隐藏或切换工作区影响浏览器会话的问题；网页访问与提取无需先打开工作区，浏览器视图在切换展示时保留。
• 修复单角色对话错误隔离参与者历史的问题，并清理已删除角色或共享记忆留下的无主记忆资源。
• 优化记忆检索，持久保存记忆及文档分块向量，在本地数据库完成筛选排序，减少大记忆库的重复加载。
• 调整多设备记忆任务：自动提取和重建由创建任务的设备执行，避免其他同步设备重复运行；恢复本机超时卡住的处理中任务。
• 优化多设备同步与空闲运行：减少无变更时的文件扫描、同步探测和 JavaScript 轮询；对探测失败及被撤销连接的设备延后重试，避免拓扑变化引起无效同步。
• 修复插件选取文件和目录后的访问路径，返回可供工具读取的资源；补齐 Apple 文件类型筛选，并保留文件大小限制。
• 修复 Operit 1 备份导入后的工作区关联，规范旧路径、空绑定及重复工作区，保留正确的聊天绑定。
• 修复插件界面并发刷新后出现“IPC 通道未注册”的问题；恢复旧版插件的系统语音播放兼容性，并提供可编辑的 Compose JavaScript 与源码示例。
• iOS：终端启动前先验证并完整准备 iSH 根文件系统，修复首次初始化中断后再次启动可能崩溃的问题。
• iOS：修复安全 WebSocket 连接的根证书配置，补齐发送位置附件所需的权限说明。

## IOS · en-US

2.0.0-preview.22 · Build 28
Changes since Build 27 (2.0.0-preview.21):

• Reworked chat Markdown rendering so live output, history and copy previews handle nested formatting, quotes and tables consistently. Fixed missing trailing content when a stream finishes and reduced repeated layout during text reveal.
• Added full-screen chat image previews with zoom and pan, with improved captions and image-only message layouts.
• Fixed errors caused by selection targets unregistering during text selection.
• Kept browser sessions alive when workspaces are hidden or switched. Web visits and extraction can start without opening the workspace, and switching views preserves the browser view.
• Fixed incorrect participant-history isolation in single-character chats and cleaned up orphaned memory resources left by deleted characters or shared memories.
• Improved memory retrieval by persisting memory and document-chunk vectors and filtering and ranking in the local database, reducing repeated loading of large memory collections.
• Changed automatic memory extraction and rebuilds to run on the device that created each task, preventing other synced devices from running the same work. Timed-out processing tasks can be recovered on their originating device.
• Reduced idle file scans, sync probes and JavaScript polling. Added retry backoff for failed probes and revoked device connections, and avoided unnecessary synchronization after topology changes.
• Fixed resource paths returned by plugin file and folder pickers, improved Apple file-type filtering and preserved file-size limits.
• Fixed workspace associations when importing Operit 1 backups, including legacy paths, empty bindings and duplicate workspaces.
• Fixed “IPC channel is not registered” errors after overlapping plugin UI renders. Restored legacy plugin system speech playback and shipped editable Compose JavaScript and source examples.
• iOS: Validate and fully prepare the iSH root filesystem before starting the terminal, fixing a startup crash path after interrupted first-time initialization.
• iOS: Fixed trust-root configuration for secure WebSocket connections and added the missing permission description for location attachments.
