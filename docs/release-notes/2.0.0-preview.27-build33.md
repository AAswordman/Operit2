# Operit2 2.0.0-preview.27 · Apple build 33

- Apple ARM64 Linux 终端默认使用原生执行器，避免短命令承担 WebKit/Wasm 的启动和传输成本。
- 新增构建配置 `OPERIT_ARM64_WASM`，默认 `OFF`；开发者可用 `-DOPERIT_ARM64_WASM=ON` 开启 Wasm 后端。iOS/macOS 打包脚本也支持同名环境变量，默认包保持关闭。
- macOS ARM64 终端运行时开启 Thin LTO。
- 调整扩展商店的卡片布局、状态展示和市场页面。

## 验证

- Wasm 关闭构建：运行时 CTest 40/40 通过。
- Wasm 开启构建：40 项原生回归通过；Wasm 集成首次因与构建并发触及 60 秒时限，单独复测于 47.73 秒通过。
- macOS 原生桥接冒烟测试：PTY、流式输出、命令取消和重启持久化通过。
- 扩展目录与市场安装状态测试：24 项通过。

上述结果不代表原始绘图脚本的完整耗时已得到验证。
