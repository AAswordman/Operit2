来源：tools/figma/software.mjs 批量采集的软件 UI 包，或单独补录的运行时场景。文件在本地处理。 导入静态图层 ZIP 或 .operit-design.json 后，可在 Figma 中修改文字、颜色、尺寸、图层及图片。
选中软件包里的一个画板或其内部图层，可导出同一软件包的全部界面修改。文字、布局、工具与插件修改均附带来源和变更记录。 整包采集会列出覆盖情况；未采集的状态需要补录。
