Operit modifications: private backend selection and publication, shell startup
identity, native supervisor, Android 17 framework enumeration compatibility,
bounded ADB I/O, in-app activation and opt-in recovery scheduling.

The original Shizuku manager card layouts, styles, icons, English/Chinese strings,
app bar, pairing tutorial and notification RemoteInput service are also included.
Card and guide layout XML is copied unchanged; unused standalone-manager resources
and strings have been removed. Kotlin UI files
identify their upstream originals; package/resource references, theme selection,
owner activation callbacks and coroutine ownership are adapted for this APK.

Standalone-manager application lists, third-party authorization/config storage,
legacy client protocol handling and rish are omitted. The retained server-shared
Binder/UserService code remains covered by the included Shizuku-API MIT license.

Stellar, ShizukuX and Brevent code is not included in this fork.
