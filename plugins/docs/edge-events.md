# 设备本地交互和通用输出流

屏幕点击由设备原生应用处理。场景命中返回本地 target，由固件选择动作并更新动画或设备状态；设备不需要等待 Core 或宿主 ToolPkg 的点击回调。

需要发给另一个端点的数据使用现有 Stream / ReverseStream，经过 Watch / Push 传输。厂商协议决定事件格式，接收方插件解释其内容。ToolPkg 的通用入口见 [edge-plugin-guide.md](edge-plugin-guide.md)。

设备配置包只编辑并保存硬件配置。显示资源和配置属于设备，配置包停止运行后，设备继续显示并处理点击。聊天仍使用原生发送与同步；音频识别、合成或其他处理由设备本地能力或者宿主插件实现。
