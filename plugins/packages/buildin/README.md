# Built-In Plugins

ToolPkg sources in this folder are packaged into Operit2 built-in plugin assets.

`automatic_ui_base.ts` migrates Operit 1's `Automatic_ui_base` device automation
package. It is disabled by default and includes localized display labels and
semantic icons for all 11 tool declarations. UI actions use the system Host provider; screenshots use
the system capture tool and VFS media registration.
