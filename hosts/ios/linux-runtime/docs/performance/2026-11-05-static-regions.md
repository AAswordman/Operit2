# 2026-11-05：静态区域后端组件优化与复测

> 历史记录：本页测量对应已删除的 C++ region/kernel 后端。当前执行器与结果见 [静态汇编执行器](../static-execution.md) 和 [交付状态](../delivery-status.md)。

本文保留上一轮结果快照；后续内存执行核修改和当前同场对照见 [内存执行核复测](2026-11-05-memory-kernels.md)。

本轮以组件本身的成本为验收对象。测量只覆盖 macOS ARM64 Release CLI（`-O3 -DNDEBUG`，LTO / sanitizer 关闭）；未构建 iOS、启动模拟器、使用设备或构建 Flutter App。rootfs 为本机 Alpine 3.23.7。原 `benchmarks/python_loop.py` 保持不变。

## 结构变化

- 地址中的单次使用 Add/Sub 常量折入内存记录位移；保留写回及共享地址表达式。成对读取的两个结果都可以分配工作位置。
- 私有页的快速权限资格在软件 TLB 填充时计算。精确页标签与 epoch 命中、单页范围、权限和文件代际验证保留；共享、并行、COW、可执行写入走既有同步路径。普通写仍使独占预留失效。
- 连续同基址的两个 64 位读取合为一条 24 字节记录：一次 16 字节跨度验证、一次分派。冷路径分开执行和捕获两条指令的故障；第二条故障时保留第一条结果及正确退休数。
- 状态导出由逐值记录改为双值 / 四值记录。CPU 字节偏移在编译时确定，四值记录打包目标偏移及槽位。导出前保存会被覆盖的输入，常量和不可打包的情况仍有精确处理。
- 区域边直接引用稳定的缓存节点；替换映像不再令全部链接失效。缓存节点淘汰才失效全部链接。目标工作位置在构建时专门化，删除逐次建立八值数组及成功链接上的重复 PC / NZCV 存储。
- 间接跳转重追踪要求连续 256 次命中同一目标，并有目标守卫；没有把多态跳转总次数当成稳定路径。推测性源编译与校验的故障不能冒充当前 PC 的故障。
- 删除成功读取不使用的 after 状态映射；写入仍保留代码失效后所需的状态。

这些记录仍由预编译函数和保证尾调用执行，不产生任意宿主机器码。局部收益不等于整个架构已经具有 JIT 的性能。

## 组件基准

每个用例每轮 134,217,728 次操作，7 轮取中位数，再反向排序复测；不含分配、编译和预热。下表为正序 / 反序中位数，单位 ns/导出值或 ns/64 位读取。

| 组件 | 正序 / 反序 ns/值 |
| --- | ---: |
| state/export-single | 0.295557 / 0.306482 |
| state/export-pair | 0.223421 / 0.232164 |
| state/export-quad | 0.189010 / 0.192371 |
| memory/typed-load | 3.245117 / 3.118759 |
| memory/checked-load | 1.995023 / 2.002982 |
| memory/load-window | 1.007256 / 1.000222 |

读取用例是已驻留的热私有页。同一基址的两个相邻值在读取窗口中共用验证；本结果不能用于推断共享页、TLB miss、跨页或缺页性能。两个用例均核对读取结果。早期短测得到的约 0.48 ns/load 不作为结论，以此处加长和反序复测为准。

单值、双值、四值导出执行同一组架构状态更新并核对最终值。另有 6,561 组四值源组合测试，包含浮点参数位置中的原始位模式、槽位 0/255/256/65535、SP 及未修改寄存器。

## 区域边对照

每轮 1,048,576 次暖区域跳转、7 轮取中位数、每区域 128 条 guest 指令。顺序为 control/candidate，然后 candidate/control；计时期间断言没有编译。

control 是本轮 B 阶段 CPU 源码快照，即稳定缓存链接、紧凑状态导出与边专门化之前的版本，使用相同非 CPU 支持库构建。它不是原始汇编解释器。源快照、构建脚本、二进制及 hash 保存于证据目录 `edge-control/`。

| 组件 | control 两次中位数 ns/区域 | candidate 两次中位数 ns/区域 |
| --- | ---: | ---: |
| edge/no-dirty-gprs | 5.617023 / 3.729424 | 5.086024 / 2.757748 |
| edge/31-dirty-gprs | 41.110635 / 41.719794 | 30.163963 / 30.111155 |

零脏寄存器用例突出链接成本；31 个脏通用寄存器用例还包括区域必要的 ALU、输入、溢出与导出，不能把整行时间叫作一条跳转指令的耗时。第一组 control 的抖动明显，不据此给出一个固定的倍数。

## 实际工作负载占比

优化前后的同一 Python 工作负载，各 3 次全进程采样及 3 次延后窗口；采样间隔 1 ms。全进程从启动后立即挂接、最长 5 秒；延后窗口从启动后 1.15 秒挂接、采 1 秒。它是固定时间偏移窗口，不保证完全排除编译。

分类器将编译和校验的子调用优先归入其父类别，再做互斥叶样本归属；每份报告验证叶样本之和等于主线程根样本。分类器同时识别新增 export_pair/export_quad、load_window、模板 edge/guard，且对优化前原始采样重算同一套分类。主线程名兼容 `Main Thread` 与 `com.apple.main-thread`。

| 类别 | 优化前全程 | 优化后全程 | 优化前延后窗口 | 优化后延后窗口 |
| --- | ---: | ---: | ---: | ---: |
| guest data memory kernels | 24.25% | 25.50% | 26.99% | 31.19% |
| state import/export and spills | 15.77% | 10.44% | 18.63% | 13.56% |
| region edges/branch/cache resolution | 12.63% | 10.06% | 14.99% | 9.84% |
| region compilation | 14.43% | 19.73% | 2.47% | 9.44% |
| code validation (including descendants) | 9.08% | 10.51% | 10.47% | 12.70% |
| ALU and constants | 12.41% | 9.50% | 14.16% | 10.38% |
| FP/SIMD semantics | 4.04% | 3.45% | 5.53% | 5.05% |
| other semantic helpers | 3.33% | 3.46% | 3.61% | 4.82% |
| other runtime/startup/system | 4.05% | 7.35% | 3.14% | 3.02% |

全程主线程样本总数：优化前 9,277，优化后 10,332；延后窗口分别 2,549 / 2,552。

状态搬运与区域控制的采样占比下降；内存、编译和校验没有显示占比下降。微基准中的两读窗口覆盖特定模式，不能代表整个内存访问类别。占比分母、动态路径和编译次数都发生了变化；不得把百分比变化直接称为绝对节省时间。栈采样不是硬件计数器，也不能分解每个内联检查、内存延迟和分派的独立周期。

## 回归与实际限制

最终同版本完整 CTest 为 **41/41 通过**，包含区域边界、CPU 校验、5,253 项硬件 ISA 审计及 rootfs 集成。region 测试还覆盖成对读取别名、第二条读取故障、预算前缀、COW、保护变更、代码失效、间接分支守卫和输入互换。可选软件包不在 rootfs 时，个别 Python 集成脚本内部会跳过对应包的子用例，不能将 41 项通过理解为所有外部包均已验证。

保持不变的原 Python 工作负载：每边预热 1 次后交替 5 次，校验 checksum=1267865。旧汇编后端 loop 中位数 **1.096110 s**，当前区域后端 **2.720791 s**；完整进程 wall 中位数为 **1.327111 / 3.843535 s**。新后端在这个真实用例上仍慢于旧后端。本报告不把局部改进作为整机提速证据，编译成本和通用执行路径仍需继续处理。

当前 CLI 24,098,976 字节；优化前采样 CLI 20,357,616 字节。静态函数专门化增加了二进制体积，组件改善不表示指令缓存压力已解决。

当前 CLI SHA-256：`ee8e41d90ffe9c4784946f3f567dba38c4114cee3993936dc7255452ffda54a3`。组件、区域边及前后采样的二进制身份见下列 JSON；代码复核后仅补了推测性校验故障边界及统计计数，最终完整回归与此采样为同一 CLI 二进制。
